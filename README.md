# Introduction to Machine Learning with Python

Repository ini berisi reproduksi kode dan rangkuman dari buku 
"Introduction to Machine Learning with Python".

Tujuan dari repository ini adalah untuk memahami konsep dasar 
Machine Learning melalui implementasi kode menggunakan Python dan scikit-learn.

## Repository Structure

### Chapter 1 - Introduction to Machine Learning
Mempelajari konsep dasar machine learning dan penggunaan dataset Iris.

### Chapter 2 - Supervised Learning
Implementasi algoritma supervised learning menggunakan K-Nearest Neighbor.

### Chapter 3 - Model Evaluation
Evaluasi performa model machine learning menggunakan accuracy.

### Chapter 4 - Representing Data and Feature Engineering
Mempelajari bagaimana merepresentasikan data dan melakukan feature engineering.

### Chapter 5 - Model Evaluation and Improvement
Teknik evaluasi model seperti cross validation untuk meningkatkan performa model.

### Chapter 6 - Algorithm Chains and Pipelines
Penggunaan pipeline untuk menggabungkan preprocessing dan model machine learning.

### Chapter 7 - Working with Text Data
Mempelajari bagaimana memproses dan menganalisis data teks menggunakan machine learning.

## Tools Used

- Python
- Scikit-learn
- Google Colab
- GitHub
